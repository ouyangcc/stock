# 🏦 富邦銀庫存管理系統 (macOS Style)

一個具備 macOS 原生視覺風格、毛玻璃質感與即時雲端同步功能的庫存管理系統。

🌐 **線上使用網址**：[https://ouyangcc.github.io/stock/](https://ouyangcc.github.io/stock/)

---

## ✨ 核心特色

- **🍎 macOS 原生質感介面**：經典紅黃綠紅綠燈控制項、毛玻璃磨砂效果（Backdrop Filter）、Apple 系統字型與按鈕微動效。
- **☁️ 即時雲端資料庫串接**：串接 Google Apps Script 後端，支援多人同時讀寫與同步。
- **🏢 多公司 / 多銀行管理**：支援即時切換與動態註冊新公司。
- **📦 完整進出貨與品項管理**：支援品項新增、編輯、刪除防呆，以及進出貨模糊搜尋登記。
- **📊 雙向 CSV 報表匯出**：
  - 一鍵匯出即時庫存清單（含 UTF-8 BOM，Excel 開啟不亂碼）。
  - 支援篩選條件之歷史流水帳紀錄 CSV 匯出。
- **📱 響應式佈局 (RWD)**：支援桌面版、平板與手機瀏覽。
